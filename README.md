# Лендинг компьютерного клуба

Сайт-«поезд»: разделы это вагоны, между ними переходишь через двери. Есть два
варианта лендинга — 2D (текущий, на `/`) и 3D-прототип на WebGL (`/train-3d`).

Стек: Next.js 15 (App Router) + React 19 + Tailwind v4 + Zod, тесты на Vitest.
3D — three.js через React Three Fiber (`@react-three/fiber`, `drei`,
`postprocessing`).

## Запуск

```bash
npm install
npm run dev
```

Next поднимется на `http://localhost:3000`; если порт занят — возьмёт соседний
свободный и напечатает адрес в консоли. 3D-версия живёт на `/train-3d`.

Перед запуском скопируй `.env.example` в `.env.local` и заполни переменные
(режим сайта, токены Telegram для формы предрегистрации).

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Дев-сервер |
| `npm run build` | Продакшн-сборка (проверяет и типы) |
| `npm test` | Прогон тестов |
| `npm run test:watch` | Тесты в watch-режиме |

Сборку и дев-сервер лучше не запускать одновременно: они делят папку `.next`, и
кэш иногда портится. Если страница внезапно пустая — останови всё, удали `.next`
и запусти дев заново.

## Что где лежит

- `app/` — маршруты и API (`app/api/pre-register` принимает заявки и шлёт в Telegram)
- `components/train/` — 2D-поезд, `components/train3d/` — 3D-сцена
- `content/site.ts` — тексты и данные лендинга
- `lib/` — режим сайта, навигация, интеграции
- `public/textures`, `public/graffiti` — ассеты сцены
- `docs/` — спеки и планы

## 3D-сцена вкратце

- `TrainScene.tsx` — сборка сцены: туннель, свет, двери, камера
- `depthNav.ts` — чистая математика перемещения камеры (покрыта тестами)
- `wagonContent.tsx` — интерактив вагонов живым HTML
- `wallPaint.ts` — статичный текст, «нарисованный» прямо в текстуре стены

Нюанс: WebGL-сцену нельзя проверить во встроенной панели превью — там документ
считается скрытым, и кадры не рисуются. Смотреть только в обычной вкладке
браузера.

Пока вся геометрия собрана кодом. Готовые модели (`.glb`) кладём в
`public/models` и подключаем через `useGLTF`.
