# Бриф для Claude Design — лендинг компьютерного клуба (Этап 1)

Документ для работы в Claude Design (claude.ai/design). Цель — собрать макеты
лендинга, затем экспортировать handoff-бандл для Claude Code (Task 22 плана).

## Как пользоваться

1. Открыть claude.ai/design → **New Project** → шаблон **Prototype** → режим
   **High Fidelity**.
2. Вставить «Главный промпт» ниже.
3. Отдельно попросить показать **два состояния главного экрана** (тизер и
   «работаем») — см. блок «Два состояния».
4. Итерации: крутить на холсте, просить менять баланс свечения, шрифты,
   расположение граффити-акцентов.
5. Когда нравится — экспортировать **handoff-бандл для Claude Code**.

## Главный промпт (копировать целиком)

> Свёрстай промо-лендинг компьютерного (игрового) клуба в уличной,
> граффити-эстетике. Язык интерфейса — русский. Одна страница со скроллом,
> адаптив под десктоп и мобильный.
>
> Настроение: тёмная база + ОДИН фирменный неоновый акцент — кислотно-зелёный.
> Важно: сдержанно, не пёстро. Кислотно-зелёный трактовать как матовую уличную
> краску (трафарет, подтёки), свечение (glow) — дозированно, только на ключевых
> кнопках и ховерах, а не везде. Граффити-элементы (теги, подтёки, трафаретные
> разделители, стикеры, скотч) — точечные акценты и разделители блоков, НЕ
> сплошной фон.
>
> Палитра: фон почти чёрный (#0a0a0a) и тёмно-серый (#151515), линии #2a2a2a,
> акцент кислотно-зелёный (#b6ff1a), текст светлый (#ededed) и приглушённый
> (#9a9a9a).
>
> Типографика: крупный «уличный» дисплейный шрифт для заголовков (условно —
> плотный конденсед в духе Oswald, обязательно с поддержкой кириллицы), чистый
> гротеск для основного текста (в духе Inter). Граффити-шрифт в основном тексте
> НЕ использовать — только акцентно.
>
> Логотип — пока заглушка «[LOGO]» в стилистике уличного тега.
>
> Блоки сверху вниз:
> 1. Закреплённая шапка: логотип · ссылки (Зоны, Цены, Как найти) · крупная
>    кнопка-CTA справа.
> 2. Главный экран (Hero) — см. отдельно два состояния.
> 3. «О клубе»: пара сильных фраз об атмосфере + 3 плитки-преимущества
>    (Топ-железо, Периферия, Атмосфера).
> 4. «Зоны»: 5 карточек — Стандарт, VIP, Консоли (PS5/Xbox), Приватная комната
>    / буткемп, Бар. У каждой: фото, заголовок, короткое описание, характеристика,
>    цена «от».
> 5. «Цены»: 3 карточки тарифов (Дневной, Ночной, Пакет 5 часов).
> 6. «Галерея»: сетка из 4–6 фото интерьера / уличного арта.
> 7. «Как нас найти»: адрес, часы работы, кнопка «Открыть в Яндекс.Картах».
> 8. Подвал: контакты (Telegram, VK, телефон, адрес) + форма «Узнать об
>    открытии» (поля: Имя, Как связаться; кнопка «Предварительная регистрация»).

## Два состояния главного экрана

Попросить Claude Design показать **оба варианта Hero** (тело страницы общее):

- **Тизер (скоро открытие):** крупный заголовок «Скоро открытие», под ним
  подзаголовок-слоган, таймер обратного отсчёта (дни · часы · минуты · секунды),
  крупная кнопка «Предварительная регистрация». Атмосферный тёмный фон с
  уличным акцентом.
- **Работаем:** крупный слоган-приглашение, строка «Открыто ежедневно
  12:00–00:00», кнопка «Забронировать место».

## Принципы (держать в каждой итерации)

- Тёмная база всегда; светлых экранов нет.
- Один акцентный цвет. Если хочется добавить второй яркий — не надо.
- Контраст и читаемость важнее «крутости»: текст на тёмном должен легко читаться.
- Граффити — приправа, а не фон.
- Мобильная версия обязана быть аккуратной: сетки в один столбец, кнопки крупные.

## Чего НЕ делать

- Не превращать в сплошной неон / киберпанк-«ёлку».
- Не использовать 3–5 ярких цветов одновременно (частая ошибка в референсах).
- Не ставить нечитаемый граффити-шрифт в описания и кнопки.
- Не добавлять блоки вне списка выше (корзина, личный кабинет, турниры — это
  следующие этапы, не Этап 1).
